# Local LLM Lab

Experiments with large language models running entirely on my own machine through [Ollama](https://ollama.com/). No cloud APIs, and no data leaves the computer.

## Prerequisites

- [Ollama](https://ollama.com/) installed and running
- At least one model pulled, for example:

```sh
ollama pull llama3.2:3b
```
