# Local LLM Lab

A benchmark comparing large language models running entirely on my own machine through [Ollama](https://ollama.com/). No cloud APIs, and no data leaves the computer.

## Models under test

| Model | Download size |
| --- | --- |
| `llama3.2:3b` | 2.0 GB |
| `llama3.1:8b` | 4.9 GB |
| `gemma3:12b` | 8.1 GB |

## Prerequisites

- [Ollama](https://ollama.com/) installed and running
- The three models pulled (about 15 GB of disk space in total):

```sh
ollama pull llama3.2:3b
ollama pull llama3.1:8b
ollama pull gemma3:12b
```
